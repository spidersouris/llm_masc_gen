`dmnt.csv` was generated from `demonette_full.csv` and `dmnt_pos.csv`, using `clean_demonette.py`.

The `clean_demonette.py` Python script requires the base human noun database `human_db_base.db`, that does not contain data from Demonette nor TLFi Recursive.

The full Demonette database `demonette_full.csv` was downloaded from the [Demonette official website](https://demonette.fr/demonext/vues/front_page.php).
